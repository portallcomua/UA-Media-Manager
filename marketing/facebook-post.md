# UA MediaManager — Facebook draft

## Українською

🗂️ **Медіатека WordPress може бути впорядкованою!**

Працюємо над UA MediaManager — інструментом для тих, хто хоче навести лад у зображеннях і файлах свого сайту.

Що вже з’явилося в тестовій збірці:
✅ Фізичні папки та вкладені каталоги для медіафайлів.
✅ Переміщення й перейменування файлів із оновленням відомих посилань WordPress.
✅ Карантин із можливістю відновлення.
✅ Пошук точних дублікатів за SHA-256.
✅ ZIP-архів медіатеки та відновлення файлів.
✅ Пакетна lossless-оптимізація JPEG, PNG і GIF — за наявності потрібних інструментів на сервері.

Зараз триває тестування сумісності та доробка ліцензування. Це ще не фінальний реліз — спершу перевіряємо безпечність операцій на тестових сайтах.

**UA MediaManager — порядок у медіатеці без зайвого ризику.**

## English

🗂️ **A more organized WordPress media library!**

We are building UA MediaManager for website owners who want a cleaner, easier-to-manage media library.

The current test build includes:
✅ Physical folders and nested media directories.
✅ File moves and renaming with updates to known WordPress references.
✅ Restorable quarantine.
✅ SHA-256 exact duplicate detection.
✅ ZIP media backup and file restoration.
✅ Batched lossless JPEG, PNG and GIF optimization when server tools are available.

Compatibility testing and licensing work are still in progress. This is not the final release — safety checks come first.

**UA MediaManager — bring order to your WordPress media library.**
